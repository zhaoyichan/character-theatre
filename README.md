# 小剧场（character-theatre）· SillyTavern 第三方插件

> 作者：liwe和他的后宫老婆们 ｜ 版本：v2.0.0 ｜ 类型：extension
> 给你的角色扮演（RP）一座「台词素材库 + 聊天收藏夹」。

---

## 它是什么

**小剧场**帮你把两条线串起来：
- **素材**：把想复用的台词、桥段存成「小剧场」，随时一键发回聊天；
- **收藏**：把精彩的聊天消息收藏下来，按角色整理，日后回看或用回去。

下面把它的功能一条条列出来，每个是干什么用的。

---

## 功能一览

### 1. 台词素材库
把想复用的对白按**分组**存成一条条「标题 + 正文」。存好后，随时能**发回聊天**或**填进输入框**。
正文里可用 `{{user}}`（你自己）和 `{{char}}`（角色），发送时自动替换成当前的名字。

### 2. 发送 / 填框
- **发送**：把这条素材作为你的发言，直接进聊天气泡（不触发 AI 自动回复）。
- **填框**：只把文字填进输入框，由你决定什么时候发送。

### 3. 聊天收集（双击 / ✓）
把聊天里想留的一段文字收进小剧场：
- **双击**一条消息，或点消息右下角的 **✓** 小图标；
- 弹窗里可选择「反替换规则」，把消息里出现的名字替换回 `{{user}}`/`{{char}}` 占位符；
- 确认后这条内容就收录进你选的小剧场分组，变成一条新素材。

### 4. 收藏聊天记录（★ / 长按）
把精彩聊天收藏下来：
- **长按**消息，或点消息右下角的 **★**，给它写个标题就收好；
- 收藏会**按角色分组**整理成折叠文件夹，点开能回看完整内容（含图片、思维链）。

### 5. 两套替换名
在设置里可分别设置「全局」和「当前聊天」两套替换名字（你叫啥、角色叫啥），可存成多个组自由切换，用于发素材时自动替换名字。

### 6. 收藏多选批量
在收藏界面勾选多条收藏，可以：**删除**、**导出成 HTML**、或**注入回聊天**（把收藏的内容重新发回当前 RP）。

### 7. 单条消息拍照 / 复制
每条消息右下角还有两个小按钮：
- **复制**：把这**一条**的文本复制到剪贴板；
- **拍照**：把这**一条**导出一张竖屏长图（PNG），显示全部文字、自动排版，相册里能直接看。

### 8. 可拖动悬浮球
右下角悬浮球**长按可拖动**到屏幕任意位置并**记住位置**，不遮挡关键界面。

### 9. 备份与恢复
设置页可一键**导出 ZIP / JSON**（含预览与数据），换设备也不怕丢收藏和素材。

---

## 界面
全 **SVG 图标、零 emoji**，单列紧凑卡片，浅色护眼；收藏界面与主界面同一套风格（浅米白 + 深藏青 + 金色）。

---

## 常见问题

- **升级后还是旧版**：完全关闭酒馆再重开（只刷新不生效）。
- **Android 目录写不了**：data 目录需 root/Shizuku 权限，用 root 方式放文件。
